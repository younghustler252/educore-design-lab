# Approved prototype baseline — v1

This folder holds the approved EDUCORE blue UI direction.

## Screens
- Dashboard
- Students
- General Settings

## Baseline requirements
- Standalone HTML, CSS, and vanilla JavaScript.
- Responsive, mobile-first behavior with an obvious navigation toggle and usable mobile navigation.
- Blue primary brand with white and soft-blue surfaces.
- Custom SVG iconography and polished SaaS components.
- Mock data only; no API or production database connections.
- Respect `prefers-reduced-motion`.

## Review checklist
- [ ] Desktop layout and interactions
- [ ] Mobile navigation and drawer behavior
- [ ] Student search filters both desktop rows and mobile cards
- [ ] Add-student demo flow validates input and updates both layouts
- [ ] Settings tabs and local-only save feedback
- [ ] Keyboard focus, labels, and accessible states
- [ ] No controls imply unavailable backend functionality

The actual HTML prototype will be checked in here after its final refinement and verification pass.
